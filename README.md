# 小问助手 · 桌面 AI 智能体

常驻屏幕右下角的「软件贾维斯」：能听、能说、能记住你，还能**真正操作你的电脑**。

## 快速开始

### 方式一：直接运行安装包（推荐）

1. 双击 `release-v1.2.0/` 下的 `小问助手 Setup.exe` 安装
2. 安装完成后从桌面或开始菜单启动
3. 右下角会出现蓝色悬浮球，**首次启动会自动弹出配置引导**：选服务商 → 填 API Key → 测连通 → 完成
   （如果跳过了引导，也可以右键托盘图标 → **设置** → 填入你的 API Key）
4. 开始使用

### 方式二：从源码运行（开发）

```bash
# 1. 安装依赖
npm install

# 2. 构建界面
npm run build:renderer

# 3. 启动
npm start
```

首次启动会自动打开面板并弹出「首次配置引导」，按提示 30 秒即可配好。
想重新走一遍：设置 → 常规 → **重新运行首次配置引导**。

### 密钥安全（重要）

- 本项目是**公开仓库**，任何真实 Key 一旦 commit 进 git 历史都视为已泄露，请立刻去服务商控制台轮换
- 本地密钥建议走环境变量：把 `.env.example` 复制为 `.env` 填入（`build/_jarvis_e2e.js` 会读 `DASHSCOPE_API_KEY`）
- `config.json` 与 `.env` 都已在 `.gitignore` 中，不会被提交
- 应用运行时，密钥只保存在本机 `%APPDATA%\xiaowen-assistant\config.json`，渲染进程拿到的始终是打码值

开发模式（界面热更新）：

```bash
# 终端 1：启动前端开发服务器
npm run dev

# 终端 2：启动 Electron
npm run dev:electron
```

## 配置 API Key

启动后右键托盘图标 → **设置**，或点击面板右上角的齿轮图标。

### 推荐：DeepSeek（便宜、中文好）

1. 访问 https://platform.deepseek.com 注册并创建 API Key
2. 在设置里「服务商」选择 **DeepSeek**
3. 粘贴 API Key
4. 点「测试连接」，显示「连接成功 ✓」即可

### 其他服务商

| 服务商 | 获取地址 | 备注 |
|---|---|---|
| 通义千问 | https://dashscope.console.aliyun.com | 有免费额度 |
| 月之暗面 Kimi | https://platform.moonshot.cn | 长文本强 |
| 智谱 GLM | https://open.bigmodel.cn | glm-4-flash 免费 |
| OpenAI | https://platform.openai.com | 需要海外网络 |

如果用的是自建或代理服务，选「自定义…」，手动填 Base URL 和模型名即可（需兼容 OpenAI 接口格式）。

## Agent 能力说明（v1.1 新增）

开启 Agent 模式（标题栏扳手图标或设置页）后，小问可以用 17 个内置工具直接操作电脑：

| 类别 | 工具 |
|---|---|
| 命令 | `shell_exec`（PowerShell / cmd / bash） |
| 文件 | `file_read` / `file_write` / `file_delete` / `file_list` |
| 系统 | `system_info` / `get_datetime` / `process_list` / `process_kill` |
| 桌面 | `app_open` / `screenshot` / `clipboard_read` / `clipboard_write` / `notify` |
| 网络 | `http_request` |
| 记忆 | `memory_add` / `memory_search` |

**安全机制**：
- 高危命令（format / shutdown / reg / diskpart 等）直接拦截
- 写/删操作只允许用户目录、下载、临时目录与白名单目录
- 高危工具执行前弹窗确认（可在设置改为全部确认或全自动）

## 语音唤醒（v1.3 新增）

开启后，直接说「小问」就能把它叫起来，不用去点悬浮球也不用按快捷键。

**开启方式**：设置 → 语音 → 语音唤醒 → 打开开关（默认关闭）。
开启后悬浮球核心会多一圈青色微光，表示它正在听。

**它是怎么工作的**（两级检测，兼顾灵敏和省钱）：

| 阶段 | 做什么 | 成本 |
|---|---|---|
| ① 本地常驻监听 | 麦克风一直开着，但只算音量判断「有没有人说话」 | 零，不发任何网络请求 |
| ② 云端确认 | 只有检测到人声，才开一次约 2~3 秒的识别，拿文本比对唤醒词 | 一次短识别 |

**几个实现上的取舍，你可能会关心：**

- **没有引入额外 Key 或模型**。专业唤醒方案（Porcupine / sherpa-onnx）要么要再申请一个 Key，要么要下载模型加原生依赖，对这个纯 JS 小工具太重。这里复用了你已经配好的语音识别通道。
- **预缓冲 700ms**。人是先说出「小问」、VAD 才反应过来的，等连上识别服务，第一个字早过去了。所以引擎会环形保留最近 700ms 的音频，会话一建立就补发过去，唤醒词不会被截断。
- **同音字放宽**。中文识别经常把「小问」写成「小文 / 小闻 / 小吻」，匹配时会按常见同音写法放宽，也可以在设置里自己加词。
- **不会自己听见自己**。面板打开或正在录音时，监听自动让出麦克风（否则 AI 的回答会被当成唤醒词，反复触发）。
- **有限流**。开着电视或开会时人声不断，1 分钟内触发超过 12 次会自动歇 5 分钟，避免默默烧掉配额。
- **常驻开麦的代价**：会一直显示麦克风占用，CPU 有一点常驻开销。介意的话关掉开关即可，双击悬浮球或 `Alt+Space` 照常能用。

## 常见问题

**Q：双击了没反应 / 托盘图标不见了？**
Windows 默认会折叠托盘图标，点任务栏的「^」展开，把小问助手拖出来固定。

**Q：程序打不开（双击一闪而过）？**
v1.0.2 已处理两类常见原因：GPU 进程崩溃、以及上次被强制结束留下的单实例锁
导致新进程误以为「已有实例在运行」而静默退出。正常情况下不会再出现。
如果仍打不开，试试：

1. 先彻底退出旧进程：任务管理器里结束所有 `小问助手.exe`，再重新双击
2. 检查托盘区（点任务栏的「^」）—— 可能程序已在运行，只是窗口被隐藏了
3. 右键 `小问助手.exe` → 以管理员身份运行
4. 检查是否被杀毒软件拦截（把程序加入白名单）
5. 删掉配置目录后重试：`%APPDATA%\xiaowen-assistant`

**Q：提示 `HTTP 401 · Incorrect API key provided`？**
说明服务端没收到正确的 Key。按顺序排查：

1. **确认 Key 完整**：到设置里重新粘贴一次完整 Key。注意不要复制到
   打码后的文本（形如 `sk-abc***wxyz`），带 `***` 的一定是无效的，
   程序也会直接拦下并提示。
2. **确认 Key 没过期/没被禁用**：登录服务商后台看 Key 状态与余额。
3. **确认 BaseURL 与 Key 匹配**：Key 是从哪家申请的，地址就要填哪家。
   比如 DeepSeek 的 Key 不能配 OpenAI 的地址。
4. **检查 BaseURL 格式**：多数服务商需要带 `/v1`
   （如 `https://api.openai.com/v1`），DeepSeek 则用
   `https://api.deepseek.com`。程序会自动去掉结尾多余的 `/`，
   也会自动识别你填了完整 `/chat/completions` 的情况。
5. 点设置里的「测试连接」，它会直接用当前填写的值发一次请求，
   比盲猜更快定位问题。

**Q：启动日志在哪？**
`%USERPROFILE%\.xiaowen\launch.log`。里面记录了渲染模式、单实例锁判定、
看门狗自检等关键信息，排查启动问题时先看它。

**Q：想启用硬件加速（追求更流畅）？**
用 `小问助手.exe --enable-gpu` 启动，或在设置里关闭「禁用硬件加速」后重启。
注意：部分显卡驱动异常的机器开启后可能无法启动。

**Q：语音识别没反应 / 提示失败？**

1. 打开设置 → 语音，点「测试语音识别」—— 这一步能准确区分问题：
   - 提示「Key 无效」→ 重新去控制台复制完整 Key（注意别复制成带 `***` 的打码文本）
   - 提示「无法连接」→ 检查网络或代理
   - 显示「连接成功」但说话没反应 → 检查麦克风权限与被占用情况
2. 确认麦克风权限：Windows 设置 → 隐私和安全性 → 麦克风
3. 确认麦克风没有被其他程序独占（如腾讯会议、钉钉）
4. 也可在设置里把「识别方式」切到「系统内置」作为备选（依赖 Google 服务，国内通常不可用）

**Q：回答没有朗读？**
设置里确认「朗读 AI 回答」开着，并点「试听」确认系统语音引擎正常。

**Q：想换悬浮球位置？**
直接拖到想要的位置，松手会自动贴边。

**Q：API 费用怎么算？**
按服务商的 token 计费，小问本身不收费。设置里可调「上下文轮数」控制 token 消耗，调小更省钱。

**Q：怎么完全退出？**
右键托盘图标 → 退出小问助手。关闭面板窗口只是隐藏，程序仍在托盘常驻。

## 渲染模式说明（重要）

程序内置了**保守的渲染策略 + 自动降级**，以优先保证「能打开」：

| 档位 | 触发条件 | 效果 |
|---|---|---|
| 软件渲染（默认） | Windows 首次启动 | 关闭硬件加速，兼容性最好 |
| 硬件加速 | 加 `--enable-gpu` 或在设置里关闭开关 | 流畅度更好 |
| 免沙箱 | Windows 上始终启用 | 规避系统/安全软件拦截子进程 |
| 崩溃自愈 | 上次启动未走完初始化 | 下次自动降级并重试 |

启动日志会打印当前档位（`[gpu]` / `[sandbox]` 前缀），排查问题时可以参考。

## 配置存储位置

```
%APPDATA%\xiaowen-assistant\
├── config.json          # 主配置（模型、Key、语音设置）
└── jarvis\
    ├── persona.json     # 人格设定（我是谁/主人是谁）
    ├── memory.json      # 长期记忆
    ├── sessions.json    # 短期记忆（多会话）
    ├── mcp.json         # MCP 服务器
    ├── tools.json       # 工具开关与白名单
    ├── skills\          # 技能包
    └── shots\           # 截图
```

设置页底部有「打开数据目录」按钮可直接跳转。

## 技术栈

- **Electron 32** — 桌面容器
- **原生 JS + Vite 5** — 无框架依赖，启动快、体积小
- **Function Calling** — Agent 工具循环（OpenAI 协议）
- **MCP (Model Context Protocol)** — 外部工具生态
- **阿里云百炼** — paraformer-realtime 识别 + CosyVoice 合成（同一 WebSocket 端点）
- **Web Speech API** — 系统语音合成（离线）
- **OpenAI 兼容接口** — 一套代码支持多家大模型
